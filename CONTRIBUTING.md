# Contributing

Спасибо за интерес к Mynx! Проект — офлайн-менеджер паролей на Tauri 2 (Rust) + React 18/TypeScript, поэтому к изменениям, затрагивающим криптографию или хранилище, отношение особое.

## Быстрый старт

```bash
npm install           # фронтенд
npm run tauri-dev     # приложение в dev-режиме (нужны Rust + Tauri-зависимости)
cd src-tauri && cargo test   # юнит-тесты ядра (криптография/формат сейфа)
```

## Правила

1. **Ветки**: фичи — от `main`, имя `feat/<тема>`, фиксы — `fix/<тема>`.
2. **Тесты обязательны** для всего, что касается `src-tauri/src/crypto/`, `vault/`, `api.rs`, `ipc.rs`: любой новый путь расшифровки должен быть покрыт roundtrip-тестом и тестом «не opens с чужим AAD/ключом».
3. **CI (Security workflow) не обходится**: `cargo test`, `cargo clippy -- -D warnings`, `npm audit` должны быть зелёными. Прагаматические исключения (`allow(clippy::…)`) — с комментарием-обоснованием.
4. **Криптография**: не менять формат сейфа, AAD-константы (`AAD_*_V2`), KDF-параметры и порядок вывода ключей без RFC-записи в `design/` и обратной совместимости (fallback на legacy-чтение обязателен).
5. **Секреты в памяти**: новые ключи/секреты — фиксированные массивы или Vec с `zeroize` на выходе; никакой sensitive-строки в логах и `eprintln!`.
6. **Формат коммитов**: conventional commits (`feat:`, `fix:`, `docs:`, `chore:`), один логический шаг — один коммит.
7. **Документация**: изменения фактов (команды Tauri, эндпоинты, формат сейфа) требуют синхронного обновления `docs/tech-stack.md` / `docs/architecture.md`. Обратите внимание: `docs/USER-GUIDE.md` импортируется приложением (`src/lib/guide.ts` через `?raw`) — структура `##`-заголовков не должна ломаться.

## Отчёт об уязвимостях

Только приватно — см. SECURITY.md. Публичные issue с деталями уязвимостей будут скрыты до релиза исправления.

## Стиль кода

Rust: `cargo fmt` перед коммитом. TypeScript: без `any` в новых модулях, eslint/prettier, если настроены в репозитории.
